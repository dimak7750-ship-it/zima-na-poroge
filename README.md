# Зима на пороге — дневник

План подготовки к 5 км (Лужники, 4 апреля 2027) и что из него выходит на деле. Данные из Garmin Connect.

Дашборд: https://dimak7750-ship-it.github.io/zima-na-poroge/

## Как оцениваются тренировки

Спокойно и честно, без лишней мотивации. Мерило — цель 5 км из 16:00 (ближайшая — 18:00–18:20 к апрелю 2027).
- Отклонения называем прямо и с цифрами, но без нагнетания.
- Хвалим, только когда есть за что, коротко.
- Выводы по данным. Если данные сомнительные (ошибка часов, калибровка), так и пишем и не делаем вывод.

## Что где лежит

- `data/plan.json` — план по неделям и дням: км, минуты субпорога, силовые, плавание, старты
- `data/activities.json` — тренировки из часов (без GPS): км, темп, пульс, минуты в Z4/Z5, ощущения и RPE
- `data/wellness.json` — состояние по дням: сон ночью (`sleep_h`), дневной сон (`nap_h`), всего (`sleep_total_h`), HRV, пульс покоя, Body Battery, готовность
- `data/notes.json` — дневник: что писал сам, что заметили часы
- `data/status.json` — порог, VO2max, нагрузка на последнее воскресенье
- `reports/` — воскресные отчёты
- `scripts/build.py` — считает недели, отклонения и собирает `data/bundle.js` для дашборда
- `scripts/send_telegram.py` — отправка отчёта в Telegram (запускается из GitHub Actions)

## Как обновляется

Всё берётся из Garmin: бег, силовые («Силовая»), прыжки (в той же силовой или HIIT), плавание, велостанок, сон, HRV.

- Каждый день в 8:07 и 23:07 по Москве задача в облаке забирает свежие данные, пересчитывает и коммитит. Дашборд обновляется сам.
- Каждое воскресенье в 22:00 — полный отчёт за неделю: `reports/`, чат и почта dimak7750@gmail.com.
- Telegram: когда в `reports/` появляется новый отчёт, GitHub Actions (`.github/workflows/telegram.yml`, `scripts/send_telegram.py`) шлёт в бота раздел «Коротко» и весь отчёт файлом. Нужен секрет репозитория `TELEGRAM_BOT_TOKEN` (бот @garmin_run_plan_bot); `TELEGRAM_CHAT_ID` необязателен — без него чат берётся из последнего сообщения боту. Проверить вручную: Actions → «Отчёт в Telegram» → Run workflow (отправит последний отчёт).

## Как считаются отклонения

- **Лёгкий быстро** — в день лёгкого бега средний пульс выше 150
- **Выше порога** — в день субпороговой работы больше 3 мин выше 182
- **Пропуск** — по плану бег, в часах ничего
- **Работа не сделана** — бег был, но субпорога меньше 8 мин
- **Объём** — неделя меньше 85% или больше 110% плана по км
- **Субпорог** — за неделю меньше 75% плановых минут
- **Силовая** — по плану есть, в часах не записана
